# Autoprogrammer

Autoprogrammer is a Python project for generating and packaging RPG-style game code.

## Features
- Reads a game blueprint
- Generates Python game code
- Uses agent prompt files for orchestration and design
- Packages output with PyInstaller

## Files
- autoprogrammer.py - main script
- rpg_backend_engineer.agent.md - backend/code generation agent prompt
- rpg_game_designer.agent.md - game design agent prompt
- rpg_orchestrator.agent.md - orchestration agent prompt

## Requirements
Install dependencies with:

```bash
pip install -r requirements.txt
```
